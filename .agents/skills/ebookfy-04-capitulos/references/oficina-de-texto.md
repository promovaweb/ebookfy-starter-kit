# Oficina de texto para um capítulo

“Confira a bancada” deixa duas perguntas: o que procurar e como saber que terminou? Uma passagem de trabalho pode dizer: “Abra a folha de materiais ao lado da caixa. Para cada peça desenhada, coloque a peça correspondente sobre a figura. Se sobrar uma figura vazia, anote o nome antes de distribuir o material à turma.”

Para adaptar a passagem, confira se a oficina realmente usa uma folha ilustrada. Se a fonte mostrar uma lista numerada, mude tanto a instrução quanto a figura.

Em um capítulo sobre o CLI, faça a mesma leitura: “Na pasta do livro, execute `ebookfy info`. Compare o primeiro título listado com o primeiro CHAPTER.md indicado no TOML.” O leitor tem um local, uma ação e dois elementos concretos para comparar.
