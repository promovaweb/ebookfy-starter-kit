# Escrever a conclusão

Leia a promessa no prefácio, o primeiro exemplo e o resultado do último capítulo. Liste o que o leitor realmente produziu. Escolha uma conferência que use esse material para mostrar se a tarefa foi concluída.

Escreva o encerramento no último CHAPTER.md ou crie uma unidade final em [[chapters]]. Quando houver uma tentativa incompleta, indique o trecho de retorno pelo título. Para propor uma aplicação seguinte, escolha uma variação que o leitor já tenha recursos para executar.

Percorra o texto com uma amostra pronta e outra incompleta. Se as duas puderem receber o mesmo “está pronto”, refine a conferência final. Revise o prefácio quando a entrega final tiver mudado.

## Referência de trabalho

Consulte [Prova final com duas amostras](references/prova-final.md) para ensaiar uma conclusão com dois resultados possíveis.

## Checklist da entrega

- [ ] O encerramento usa algo que o leitor preparou nos capítulos.
- [ ] Há uma forma observável de reconhecer uma falta e retomar a tarefa.
- [ ] A última orientação pode ser executada com os recursos apresentados.
