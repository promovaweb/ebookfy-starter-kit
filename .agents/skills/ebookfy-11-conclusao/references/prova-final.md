# Prova final com duas amostras

No caderno da oficina, deixe sobre uma mesa a bancada completa e, sobre outra, uma caixa com um compartimento vazio. Leia apenas o fechamento. A frase “agora você sabe preparar uma bancada” serviria para as duas mesas. Experimente uma orientação verificável: “Passe o dedo por cada linha da folha de materiais. Para as linhas sem marca, volte ao compartimento indicado antes de abrir a sala.”

Para uma obra sobre publicação, use a mesma técnica com uma pasta contendo os três formatos e outra contendo somente o PDF. Peça para comparar os arquivos encontrados com os formatos prometidos e identificar qual exemplar precisa ser gerado novamente.
