# Distribuir a edição

Parta da lista devolvida pelo build da edição aprovada. Relacione formato, caminho, tamanho e SHA-256. Confira book.rights, versão e destino indicado pelo responsável. Se o pedido cobrir apenas preparação, entregue os arquivos e a relação de conferência.

Quando o envio estiver autorizado, transfira os exemplares à pasta ou canal previsto. Abra cada link pela mesma forma de acesso prevista para o leitor e compare o arquivo recuperado com a cópia local. Em material privado, teste com uma conta que tenha o acesso esperado.

Ao encontrar diferença, localize a origem: arquivo selecionado, nome usado no destino ou cache de uma edição anterior. Registre os links conferidos e os formatos pendentes. Preserve exemplares antigos conforme o acordo editorial.

## Referência de trabalho

Consulte [Conferência da cópia distribuída](references/conferencia-da-entrega.md) para comparar o original com a cópia recebida.

## Checklist da entrega

- [ ] A relação de entrega contém somente os formatos solicitados desta edição.
- [ ] O destino e a forma de acesso correspondem ao combinado.
- [ ] Cada cópia conferida tem hash igual ao original e abre no leitor previsto.
